# Google Homepage 

## Overview

This project is a recreation of the Google homepage, developed as a front-end development practice project.

The main goal was to reproduce Google's familiar homepage layout while improving my understanding of HTML structure, CSS styling, and web page positioning.

## Features

- Google-style homepage layout
- Search bar design
- Navigation menu
- Google logo placement
- Responsive layout (if implemented)
- Clean and structured HTML and CSS code

## Technologies Used

- HTML5
- CSS3

![Google Homepage Preview](screenshots/google-homepage.png)

## Learning Outcomes

Through this project, I practiced:

- Structuring web pages using HTML
- Styling elements with CSS
- Working with layouts and positioning
- Recreating an existing user interface
- Improving attention to visual details

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
